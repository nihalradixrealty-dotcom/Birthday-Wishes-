# Birthday Wishes - Interactive Celebration Website 🎉

A beautiful, interactive birthday celebration website with OTP verification, balloon popping, candle blowing, and a vintage letter experience.

## Features ✨

### 1. **OTP Verification Screen** 🔐
   - Welcome screen with OTP verification
   - OTP: `11337` ("one tea" - 1 + tea in leetspeak)
   - Secure access to the celebration

### 2. **Interactive Activities** 🎊
   - **🎈 Balloon Popping**: Click balloons to pop them with satisfying animations
   - **🕯️ Candle Blowing**: Click candles to blow them out, making a wish!
   - **Progress Tracking**: Visual progress bar showing completion

### 3. **Vintage Letter** 💌
   - Beautifully designed vintage-style letter
   - Opens after completing all activities
   - Personalized birthday message
   - Elegant, nostalgic aesthetic

### 4. **Celebration Effects** 🎆
   - Confetti animations throughout
   - Pop and wind effects
   - Smooth transitions and animations
   - Responsive design for all devices

## How to Use 🚀

1. **Enter OTP**: Start by entering the OTP (hint: "one tea" 🍵)
2. **Pop Balloons**: Generate and click on balloons to pop them
3. **Blow Candles**: Generate and click on candles to blow them out
4. **Open Letter**: Once both activities are complete (100% progress), open the vintage letter
5. **Celebrate**: Enjoy the confetti and birthday wishes!

## Customization 🎨

### Change OTP
Edit `script.js` line 2:
```javascript
const CORRECT_OTP = '11337'; // Change this value
```

### Customize Letter Content
Edit the letter text in `index.html` within the `.vintage-letter` section

### Modify Colors
Change gradient colors in `styles.css`:
```css
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
```
